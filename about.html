考古报告实体标注知识库的背景与方法说明

🎯 项目背景

中国考古学专刊·丁种是中国社会科学院考古研究所编辑出版的大型考古报告丛书，自1952年出版第一种（辉县发掘报告）以来，已累计出版八十余种，涵盖了中国考古学史上几乎所有重大遗址的正式发掘报告。

这些报告内容极为丰富，包含了大量的遗迹编号、器物编号、年代数据、地理位置、地层信息等结构化数据，但目前均以PDF形式存在，难以进行数据化利用。

本项目旨在对这批重要考古报告进行全文提取 + 实体自动标注，构建一个结构化的知识库，便于考古学研究者快速检索和分析报告内容。

⚙️ 技术方法

本项目的处理流程如下：

  1. PDF获取：从 Internet Archive 等渠道获取考古学专刊·丁种的PDF扫描版
  2. 文本提取：使用 MinerU API 将PDF转换为Markdown格式文本（保留标题层级、表格结构）
  3. 实体标注：使用自研Python脚本进行26类考古实体的自动识别与标注
  4. 数据结构化：将标注结果组织为JSON格式，按报告和实体类别索引
  5. 可视化展示：生成交互式HTML知识库网站，支持搜索、筛选、统计

📚 原始PDF获取

考古学专刊·丁种的原始PDF可通过以下渠道获取：

  • Internet Archive：archive.org/details/archaeology-dingzhong （约95册，需代理访问）
  • 全国图书馆参考咨询联盟：ucdrs.superlib.net （可免费文献传递）
  • 各大学术数据库：知网、万方等平台的博硕论文中有部分引用和转载

📜 使用说明

本站为静态网站，所有数据已嵌入页面中，无需后端服务。

  • 在总览页可查看所有报告的统计图表和筛选表格
  • 在报告列表页可按时代分类浏览报告卡片
  • 点击任意报告进入详情页，可查看实体标注和报告全文
  • 报告全文中的图片标注为「本地图片」，需下载完整数据包后在本地查看
  • 在数据下载页可获取JSON实体数据、Markdown全文等结构化数据
