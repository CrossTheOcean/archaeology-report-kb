### 🔍 推荐获取步骤

**步骤一：全国图书馆参考咨询联盟（最推荐）**
1. 访问 [www.ucdrs.superlib.net](https://www.ucdrs.superlib.net)
2. 免费注册账号
3. 搜索书名 → 找到后点击"图书馆文献传递"
4. 填写邮箱，通常1—3天收到PDF（每次可申请全书或部分章节）

**步骤二：Z-Library / Anna's Archive（旧版扫描PDF最多）**
1. 搜索 "z-library" 最新可用域名
2. 搜索中文书名
3. 下载PDF（出版年代较早的报告大多有扫描版）

**步骤三：CADAL大学数字图书馆**
1. 访问 [www.cadal.edu.cn](https://www.cadal.edu.cn)
2. 注册后搜索书名
3. 在线浏览或申请下载

**步骤四：知网/超星（需机构账号或付费）**
1. 搜索书名 → 部分有电子书可购买
2. 知网镜像站（如高校知网）可下载
3. 超星可通过全国图书馆联盟文献传递

**步骤五：文物考古知识服务平台**
1. 访问 [kgy.cnki.net](https://kgy.cnki.net)
2. 需机构订阅（社科院、部分高校有权限）
3. 收录文物出版社全部考古报告电子版
